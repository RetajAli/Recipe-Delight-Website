# Recipe Delight Website

## Overview

Recipe Delight is a full-stack web application that allows users to explore, save, and manage cooking recipes through a personalized experience.

The system supports both User and Admin roles. Users can browse recipes, save favorites, manage their profile, and search for recipes. Administrators can manage users, monitor activity, view statistics, and maintain website content.

## Features

### User Features

* User Registration
* User Login
* Session-Based Authentication
* Browse Recipes
* Search Recipes
* Save Favorite Recipes
* Manage Favorites
* User Profile Management

### Admin Features

* Admin Login
* Dashboard Analytics
* User Management
* Favorite Recipes Management
* User Search
* Activity Monitoring
